EXP 02
Booth Multiplication
Signed binary multiplication · C program

Aim

To implement Booth’s multiplication algorithm for multiplying two signed binary numbers.

Program

#include <stdio.h>

int main() {
    int m, q, a = 0, q1 = 0, n, count;

    printf("Enter Multiplicand (M): ");
    scanf("%d", &m);
    printf("Enter Multiplier (Q): ");
    scanf("%d", &q);

    n = 4;
    count = n;

    printf("\nCount\tA\tQ\tQ-1\tOperation\n");

    while (count--) {
        int q0 = q & 1;

        if (q0 == 1 && q1 == 0)
            a -= m;
        else if (q0 == 0 && q1 == 1)
            a += m;

        printf("%d\t%04d\t%04d\t%d\t%s\n",
               n - count, a & 15, q & 15, q1,
               q0 == q1 ? "ASR" : (q0 ? "A=A-M" : "A=A+M"));

        q1 = q & 1;
        q = (q >> 1) | ((a & 1) << 3);
        a >>= 1;
    }

    printf("\nFinal Product (A,Q): %d\n", a * 16 + q);
    return 0;
}

Algorithm (short)

  1. Read M and Q; initialize A = 0 and Q-1 = 0.
  2. Check the pair Q₀, Q-1.
  3. For 10 subtract M from A; for 01 add M.
  4. Perform arithmetic shift right on A, Q and Q-1.
  5. Repeat four times and combine A and Q.
EXP 3.1
Restoring Division
Binary division · C program

Aim

To implement the restoring division algorithm to find the quotient and remainder of two binary numbers.

Program

#include <stdio.h>

int main() {
    int Q, M, A = 0, n = 4;

    printf("Enter Dividend: ");
    scanf("%d", &Q);
    printf("Enter Divisor: ");
    scanf("%d", &M);

    for (int i = 0; i < n; i++) {
        A = (A << 1) | ((Q >> (n-1)) & 1);
        Q = (Q << 1) & 15;
        A -= M;

        if (A >= 0)
            Q |= 1;
        else {
            A += M;
            Q &= ~1;
        }
    }

    printf("\nQuotient = %d", Q);
    printf("\nRemainder = %d\n", A);
    return 0;
}

This version uses 4-bit unsigned inputs. Enter a non-zero divisor within the supported range.

Algorithm (short)

  1. Initialize A = 0 and set n = 4.
  2. Shift A and Q left, bringing the next dividend bit into A.
  3. Subtract divisor M from A.
  4. If A is non-negative, set the least significant bit of Q to 1.
  5. If A is negative, restore A by adding M back and set Q's last bit to 0.
  6. Repeat four times. Q is the quotient and A is the remainder.
EXP 3.2
Non-Restoring Division
Binary division · C program

Aim

To implement the non-restoring division algorithm to calculate the quotient and remainder of two binary numbers.

Program

#include <stdio.h>
int main() {
    int Q, M, A = 0, n = 4;
    printf("Enter Dividend: ");
    scanf("%d", &Q);
    printf("Enter Divisor: ");
    scanf("%d", &M);

    for (int i = 0; i < n; i++) {
        A = (A << 1) | ((Q >> (n-1)) & 1);
        Q = (Q << 1) & 15;
        if (A >= 0) A -= M;
        else A += M;
        if (A >= 0) Q |= 1;
        else Q &= ~1;
    }

    if (A < 0) A += M;
    printf("\nQuotient = %d", Q);
    printf("\nRemainder = %d\n", A);
    return 0;
}

This code uses 4-bit unsigned inputs. Enter a non-zero divisor within the supported range.

Algorithm (short)

  1. Initialize A = 0 and set n = 4.
  2. Shift A and Q left, bringing the next dividend bit into A.
  3. If A is non-negative, subtract divisor M; otherwise add M.
  4. If A is non-negative, set Q's last bit to 1; otherwise set it to 0.
  5. Repeat four times.
  6. If A is negative, add M to restore the final remainder.
  7. Q is the quotient and A is the remainder.
EXP 05
Higher and Lower-Order Memory Interleaving
Memory organization · C program

Aim

To implement higher-order and lower-order memory interleaving and determine the corresponding bank number and offset for a given memory address.

Program

#include <stdio.h>

int main() {
    int addr, low_bank, low_offset, high_bank, high_offset;

    printf("Enter Memory Address: ");
    scanf("%d", &addr);

    low_bank = addr % 4;
    low_offset = addr / 4;

    high_bank = (addr / 4) % 4;
    high_offset = addr % 4;

    printf("\n--- LOW-ORDER RESULT ---");
    printf("\nBank: %d | Offset: %d\n", low_bank, low_offset);

    printf("\n--- HIGH-ORDER RESULT ---");
    printf("\nBank: %d | Offset: %d\n", high_bank, high_offset);

    return 0;
}

Enter a non-negative memory address. This program assumes four memory banks.

Algorithm (short)

  1. Start and input the memory address.
  2. For low-order interleaving, calculate bank = address % 4 and offset = address / 4.
  3. For high-order interleaving, calculate bank = (address / 4) % 4 and offset = address % 4.
  4. Display the low-order bank and offset.
  5. Display the high-order bank and offset.
  6. Stop.
EXP 06
MESI Cache Consistency Model
Cache coherence · C program

Aim

To simulate basic MESI cache-state changes in response to processor read and write operations.

Program

#include <stdio.h>

int main() {
    char state, op;

    printf("Enter Cache State (M/E/S/I): ");
    scanf(" %c", &state);
    printf("Enter Operation (R/W): ");
    scanf(" %c", &op);

    if (op == 'R' || op == 'r') {
        if (state == 'I')
            state = 'E';
        printf("Processor Read (PrRd)\n");
    } else {
        state = 'M';
        printf("Processor Write (PrWr)\n");
    }

    printf("Final State = %c\n", state);
    return 0;
}

This is a simplified MESI model for practical demonstration; real MESI transitions depend on other caches and bus transactions.

Algorithm (short)

  1. Start and input the cache state (M, E, S or I).
  2. Input the processor operation (R or W).
  3. If the operation is read, change I to E and display PrRd.
  4. If the operation is write, change the state to M and display PrWr.
  5. Display the final cache state.
  6. Stop.
EXP 08
FIFO, LRU and LFU
Page replacement algorithms · C program

Aim

To simulate FIFO, LRU and LFU page replacement algorithms and calculate the total number of page hits and page faults.

Program

#include <stdio.h>
int main() {
    int p[30], f[10], t[10], freq[10]={0};
    int n,m,i,j,k,hit,fault;
    char ch;

    printf("Enter number of pages: ");
    scanf("%d",&n);
    printf("Enter page reference string: ");
    for(i=0;i<n;i++) scanf("%d",&p[i]);
    printf("Enter number of frames: ");
    scanf("%d",&m);
    printf("Enter F=FIFO, L=LRU, U=LFU: ");
    scanf(" %c",&ch);

    for(i=0;i<m;i++) f[i]=-1,t[i]=0;
    hit=fault=0;

    for(i=0;i<n;i++) {
        for(j=0;j<m && f[j]!=p[i];j++);
        if(j<m) hit++,freq[j]++;
        else {
            fault++;
            for(j=0;j<m && f[j]!=-1;j++);
            if(j==m) {
                j=0;
                for(k=1;k<m;k++)
                    if(ch=='F' ? t[k]<t[j] :
                       ch=='L' ? t[k]<t[j] : freq[k]<freq[j]) j=k;
            }
            f[j]=p[i]; t[j]=i; freq[j]=1;
        }
        printf("%d\t",p[i]);
        for(j=0;j<m;j++) printf("%d ",f[j]);
        printf("\t%s\n",j==m ? " " : "");
    }
    printf("Total Page Faults = %d\n",fault);
    printf("Total Page Hits = %d\n",hit);
    return 0;
}

Enter F for FIFO, L for LRU, or U for LFU. Use 1–30 pages and 1–10 frames.

Algorithm (short)

  1. Input the page reference string, number of frames, and replacement method.
  2. Initialize all frames as empty and set hit and fault counts to zero.
  3. For each page, check whether it is already in a frame.
  4. If present, count a hit; otherwise count a page fault.
  5. If no empty frame exists, replace a page using FIFO, LRU, or LFU.
  6. Display the frames after each page and print total hits and faults.
EXP 09
Simulation of Data Hazards in a Pipeline
Pipeline dependencies · C program

Aim

To simulate and identify RAW (Read After Write), WAR (Write After Read), and WAW (Write After Write) data hazards between pipeline instructions.

Program

#include <stdio.h>
#include <string.h>

int main() {
    char d[10][10], s1[10][10], s2[10][10];
    int n,i,j;

    printf("Enter number of instructions: ");
    scanf("%d",&n);

    for(i=0;i<n;i++) {
        printf("Instruction %d (dest src1 src2): ",i+1);
        scanf("%9s%9s%9s",d[i],s1[i],s2[i]);
    }

    printf("\n--- DATA HAZARD ANALYSIS ---\n");
    for(i=0;i<n;i++)
      for(j=i+1;j<n;j++) {
        if(!strcmp(d[i],s1[j]) || !strcmp(d[i],s2[j]))
          printf("RAW: I%d -> I%d\n",i+1,j+1);
        if(!strcmp(s1[i],d[j]) || !strcmp(s2[i],d[j]))
          printf("WAR: I%d -> I%d\n",i+1,j+1);
        if(!strcmp(d[i],d[j]))
          printf("WAW: I%d -> I%d\n",i+1,j+1);
      }
    return 0;
}

The program includes <string.h> for strcmp() and limits each input token to 9 characters to fit the arrays.

Algorithm (short)

  1. Start and input the number of instructions.
  2. For each instruction, input destination, source 1 and source 2 registers.
  3. Compare every instruction with each later instruction.
  4. If an earlier destination matches a later source, report RAW.
  5. If an earlier source matches a later destination, report WAR.
  6. If both destinations match, report WAW.
  7. Display all detected hazards and stop.
EXP 10
4-State Dynamic Branch Prediction
Branch prediction · C program

Aim

To simulate a 4-state dynamic branch predictor and calculate the number of correct predictions, wrong predictions, and prediction accuracy.

Program

#include <stdio.h>

int main() {
    int state = 0, n, i, correct = 0;
    char actual;

    char *names[] = {"WNT", "WT", "ST", "SNT"};

    printf("Enter number of branches: ");
    scanf("%d", &n);

    printf("\nStep\tBefore\tPredicted\tActual\tResult\tAfter\n");

    for(i = 1; i <= n; i++) {
        int before = state;
        char pred = (state >= 2) ? 'T' : 'N';

        printf("Enter actual outcome (T/N): ");
        scanf(" %c", &actual);

        if(pred == actual) correct++;
        if(actual == 'T') {
            if(state < 3) state++;
        } else {
            if(state > 0) state--;
        }

        printf("%d\t%s\t%c\t\t%c\t%s\t%s\n",
            i, names[before], pred, actual,
            pred == actual ? "CORRECT" : "WRONG",
            names[state]);
    }

    printf("\nCorrect Predictions: %d", correct);
    printf("\nWrong Predictions: %d", n-correct);
    printf("\nTotal Branches: %d", n);
    printf("\nAccuracy: %.2f%%\n", 100.0*correct/n);

    return 0;
}

Enter T for taken or N for not taken at each branch. Accuracy is calculated from the number of correct predictions.

Algorithm (short)

  1. Initialize the predictor state and correct-prediction counter to zero.
  2. Input the number of branches.
  3. Predict Taken (T) for strong/weak taken states and Not Taken (N) for not-taken states.
  4. Input the actual branch outcome and compare it with the prediction.
  5. Update the 2-bit saturating counter toward Taken or Not Taken.
  6. Display each prediction and updated state.
  7. Calculate and display correct predictions, wrong predictions, and accuracy.

State note

The conventional 2-bit saturating-counter order is WNT → WT → ST for increasing taken outcomes, and WNT → SNT for the opposite end. The supplied code uses the labels in its own array order; its state names may not match the conventional order exactly.
